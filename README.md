# From LLMs to AI Agents: Transforming Professional Productivity

Repository: [TechieTripathi/llm-to-agents](https://github.com/TechieTripathi/llm-to-agents) · Online deck: [techietripathi.github.io/llm-to-agents](https://techietripathi.github.io/llm-to-agents/)

A 65-slide, two-hour workshop deck for IT and non-IT professionals, built with [Slidev](https://sli.dev) (Vue 3). Interactive artifacts are Vue components; every factual claim is cited, and all sources are collected in an appendix after slide 65.

## Requirements

- Node.js 20 or later (tested with Node 22)
- Run `npm install` once. For PDF export, also run `npx playwright install chromium` once.

## Present

```bash
npm run dev            # opens http://localhost:3030
```

- Presenter view with speaker notes and timer: `http://localhost:3030/presenter`
- Advance with → / space / clicker. Artifacts that step through states follow the clicker; their on-screen buttons also work.
- `o` opens the slide overview, `f` toggles fullscreen.

### Offline delivery

```bash
npm run build          # static site in exports/spa
npx vite preview --outDir exports/spa   # or serve exports/spa with any static server
```

Fonts, data and components are bundled; no network is needed during the talk. The two live browser demos (slides 34 and 58) run in a separate browser window and have prepared in-deck fallbacks.

## Export

```bash
npm run export          # exports/llm-agents-productivity-all-steps.pdf — one page per click state (353 pages)
npm run export:handout  # exports/llm-agents-productivity-handout.pdf — each slide once, final state (75 pages)
npm run export:notes    # exports/speaker-notes.pdf
```

The PDF captures each click state of step-driven artifacts. Free-form controls (sliders, text inputs) appear in their default state, which is designed to be meaningful on its own.

## Publish on GitHub

- **Online deck (GitHub Pages):** `.github/workflows/deploy.yml` runs the deck checks, builds the deck and deploys it on every push to `main`. One-time setup: in the repository, go to *Settings → Pages → Source* and choose **GitHub Actions**. The deck is then at **https://techietripathi.github.io/llm-to-agents/**.
- **PDFs:** `exports/` is not committed (it is regenerated by `npm run export*`). Attach the handout and speaker-notes PDFs to a GitHub release instead.

Speaker notes are the HTML comment at the end of each slide.

### Citations

1. Add the source to `data/refs/s<N>.ts` (or reuse a key from `data/refs/core.ts`).
2. List the key in the slide's frontmatter: `sources: [liu2024lost]`. The footer shows its number.
3. Optionally cite inline with `<Cite k="liu2024lost" />`.

Sources are numbered automatically in order of first citation.

### Working on one section

Each section has its own dev entry, so you can preview it in isolation:

```bash
npx slidev dev-s3.md --port 3033
```

## Checks

```bash
npm run check                   # 65 slides, sections, notes on every slide, citation keys, timing = 120 min
npm run check:urls              # every source URL resolves
node scripts/shot.mjs <port> <outDir> 12:0 12:3          # screenshot slides/click states from a running server
node scripts/contact-sheet.mjs <port> <outDir> 1 65      # first/last state of each slide, as review sheets
node scripts/check-sources-fit.mjs <port> 67 10          # every Sources page fits in two columns
```

If you add sources, re-run `check-sources-fit` and adjust `:per-page` / the number of pages in `pages/99-sources.md`.
