**Time:** ~1 min
**Objective:** Set expectations: a practical, accurate workshop about using LLMs, AI tools and agents to do professional work faster and more reliably — not a product pitch and not a programming course.
**Say:** Welcome. Over the next two hours we will go from what a large language model actually is, to how to give it the right context, how tools and browsers extend it, how agents work, and how to build reliable workflows around all of it. The goal is practical: by the end you should be able to look at a task in your own job and decide whether AI fits, how to set it up, and how to check the result. Nobody needs to install anything or write code.
